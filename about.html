Contest Bell - Never Miss a Coding Contest

About Contest Bell

Contest Bell is a coding contest notification service for competitive programmers.

Contest Bell helps programmers keep track of upcoming coding contests and receive notifications so they never miss an important contest.

What does Contest Bell do?

Contest Bell collects information about coding contests from competitive programming platforms and helps users stay informed about upcoming contests.

Users can create an account, choose their contest preferences, and receive email notifications about contests they are interested in.

Google Calendar Integration

Contest Bell also provides an optional Google Calendar integration. Users can connect their Google Calendar and add coding contests to their calendar.

Google Calendar access is only used when a user chooses to connect their Google Calendar with Contest Bell.
